# 售后退换货政策

## 适用范围

本规则适用于平台自营商品。第三方商家商品、跨境商品、定制商品、虚拟商品可能适用单独规则，以商品详情页和订单页展示为准。

## 七天无理由退货

用户自签收商品次日起 7 天内，可以申请无理由退货。申请时需满足以下条件：

1. 商品主体、配件、赠品、发票、保修卡齐全。
2. 商品未出现人为损坏、明显使用痕迹或影响二次销售的情况。
3. 原包装、吊牌、防伪标签尽量保持完整。
4. 订单未处于售后纠纷、退款处理中或异常风控状态。

## 不支持无理由退货的情况

以下场景通常不支持无理由退货：

1. 定制类商品，例如刻字、专属配置、私人订制包装。
2. 虚拟商品，例如会员卡、兑换码、充值服务。
3. 生鲜、食品、贴身用品等拆封后影响二次销售的商品。
4. 已激活或绑定账号的电子设备，且商品页明确说明不支持无理由退货。
5. 超过售后期限的订单。

## 质量问题退换货

如果商品存在质量问题，用户可以在售后有效期内提交退货、换货或维修申请。客服会要求用户提供问题描述、图片、视频或检测报告。经审核确认后，平台将按规则承担退回运费。

常见质量问题包括：

- 商品无法正常开机或使用。
- 商品功能与详情页描述明显不符。
- 商品存在破损、缺件、错发、漏发。
- 商品在正常使用场景下出现非人为故障。

## 售后处理流程

1. 用户在订单页提交售后申请。
2. 客服在 24 小时内完成初审。
3. 审核通过后，用户按页面提示寄回商品。
4. 仓库签收并质检，通常 1 到 3 个工作日内完成。
5. 质检通过后，系统原路退款或安排换货。

## 运费规则

- 无理由退货：通常由用户承担寄回运费。
- 质量问题、错发、漏发：审核确认后由平台承担合理运费。
- 到付件：未提前与客服确认的到付件可能被拒收。

## 退款时效

退款将在售后审核通过后原路退回。银行卡退款通常 1 到 5 个工作日到账，第三方支付退款通常 24 小时内到账，具体以支付机构处理时间为准。

## 客服建议话术

如果用户描述不清楚，客服应先追问订单号、商品名称、签收时间、问题现象和图片视频。不要在证据不足时直接承诺退款或换货。
