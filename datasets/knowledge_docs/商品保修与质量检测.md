# 商品保修与质量检测

## 保修范围

平台自营商品通常按照国家三包政策、品牌保修政策和商品详情页说明提供保修服务。不同品类的保修期限和服务方式可能不同。

常见保修凭证：

- 订单号。
- 发票。
- 商品序列号。
- 保修卡。
- 品牌检测报告。

## 不属于保修范围的情况

以下情况可能不属于免费保修：

1. 人为损坏，例如摔落、进水、挤压、私自拆修。
2. 超过保修期限。
3. 无法提供有效购买凭证。
4. 商品序列号被涂改或无法识别。
5. 未按说明书要求使用导致损坏。

## 检测流程

1. 用户提交售后申请并描述故障。
2. 客服判断是否需要图片、视频或品牌检测。
3. 商品寄回仓库或品牌售后点。
4. 专员进行质检并给出结论。
5. 根据结论安排维修、换货、退款或退回。

## 检测时效

普通质检通常需要 1 到 3 个工作日。品牌检测可能需要 3 到 15 个工作日。节假日、大促期间或偏远地区可能延迟。

## 客服注意事项

客服不能在未检测前直接承诺质量问题成立。对于用户情绪较强、金额较高或多次售后失败的订单，应及时升级人工工单。
