# 会员积分与优惠券规则

## 会员等级

平台会员等级根据用户近 12 个月的有效消费金额、订单数量和活跃度综合计算。会员等级越高，可能享受更高积分倍率、专属优惠券、优先客服等权益。

常见等级：

- 普通会员。
- 银卡会员。
- 金卡会员。
- 黑金会员。

## 积分获取

用户完成有效订单后可以获得积分。积分通常在订单完成且售后期结束后发放。

以下场景可能不发放积分：

1. 订单取消。
2. 订单全额退款。
3. 虚拟商品或特殊商品。
4. 使用违规账号或异常交易。

## 积分使用

积分可以用于兑换优惠券、抵扣部分订单金额或参与会员活动。具体抵扣比例以活动页展示为准。

积分使用限制：

- 积分不可提现。
- 积分不可转赠。
- 积分可能存在有效期。
- 退款时已使用积分可能按规则退回或作废。

## 优惠券类型

常见优惠券包括：

- 满减券。
- 折扣券。
- 品类券。
- 新人券。
- 会员专属券。
- 运费券。

## 优惠券使用限制

优惠券可能受以下条件限制：

1. 使用时间。
2. 商品品类。
3. 最低消费金额。
4. 是否可与其他活动叠加。
5. 用户身份或会员等级。

## 优惠券退款规则

如果订单全额退款，未过期优惠券通常会退回。部分活动券、过期券、一次性券可能不退回。部分退款时优惠券是否退回以系统计算结果为准。
