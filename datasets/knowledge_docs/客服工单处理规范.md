# 客服工单处理规范

## 工单创建场景

以下场景建议创建人工客服工单：

1. 用户明确要求转人工。
2. 连续多次低置信度回答。
3. 用户反馈答非所问或未解决问题。
4. 涉及退款、赔付、投诉、物流丢件、发票重开。
5. 订单金额较高或问题可能引发纠纷。

## 工单优先级

高优先级：

- 支付扣款未生成订单。
- 显示签收但用户未收到。
- 高金额订单退款异常。
- 用户投诉或明确表示升级。

中优先级：

- 普通退换货审核。
- 物流长时间未更新。
- 发票重开。

低优先级：

- 普通商品咨询。
- 活动规则解释。
- 会员积分说明。

## 处理流程

1. 查看用户原始问题和 AI 回答。
2. 查看订单号、会话上下文和来源信息。
3. 判断是否需要补充用户信息。
4. 给出处理结论或继续追问。
5. 更新工单状态和客服备注。

## 工单状态

- open：新建，尚未领取。
- processing：已领取，处理中。
- resolved：已解决。
- closed：已关闭。

## 备注规范

客服备注应包含处理依据、用户诉求、处理结果和下一步动作。不要在备注中记录无关信息或敏感隐私。
